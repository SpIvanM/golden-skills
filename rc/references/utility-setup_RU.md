# Протокол настройки утилит

[English version (utility-setup.md)](./utility-setup.md)

## Цель
Автоматизировать установку утилит и прямой запуск без предварительных проверок.

## 1. Директивы вызова и исполнения
- Автоматизируй детерминированные операции скриптами в папке `scripts/`.
- Предписывай прямой вызов CLI-утилит, предполагая их наличие в PATH.
- ‼ Проверка наличия или --version утилит перед вызовом строго запрещена.
- Добавляй правило «Если утилита не найдена, прочитай [setup.md](./setup.md)».
- Описывай кроссплатформенную установку в файле setup_task.md.

## 2. Шаблоны настройки утилит

### Готовый шаблон: setup.md
```text
# Протокол установки утилит
- Делегируй установку субагенту devops через invoke_subagent.
- Передай задачу: выполнить настройку окружения согласно setup_task.md.
- Продолжи исполнение навыка после завершения субагента devops.
```

### Готовый шаблон: setup_task.md
```text
# Задача установки: <утилита>
- Установи на Windows через mise или пакетный менеджер в PATH.
- Установи на WSL или Linux через пакетный менеджер в PATH.
- Установи на macOS через brew в системный PATH.
- Убедись в доступности бинарника через PATH без ошибок.
```
