# Протокол создания подскиллов

[English version (subskill-authoring.md)](./subskill-authoring.md)

## Цель
Стандартизировать создание модульных подскиллов без дублирования правил с наследованием контекста.

## 1. Структура подскилла и наследование
- Создавай подскилл по [skill-authoring_RU.md](./skill-authoring_RU.md), применяя отличия ниже.
- Опускай YAML frontmatter в файлах подскиллов внутри references/.
- Опускай раздел цели при совпадении с базовым навыком.
- Опускай раздел роли при совпадении с базовым навыком.
- Опускай мышление и шаги, если нет процедурного процесса.
- ‼ Дублирование правил базового навыка в подскилле строго запрещено.

## 2. Иерархия, именование и навигация
- Именуй файлы подскиллов в kebab-case с парным зеркалом _RU.md.
- Размещай дочерние подскиллы во вложенных подпапках references/.
- Ссылайся на соседние подскиллы через относительные пути внутри references/.
- Связывай уровни правилом «Если <кейс>, прочитай [<подскилл>](<путь>)».
- ✅ Если проверяешь юрлицо, прочитай [inn_RU.md](./validation/inn_RU.md).
- 💬 Разработка формы -> валидация -> данные юрлиц -> ИНН.
